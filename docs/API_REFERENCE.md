# HTTP API reference — public v4.2

Base URL (local): `http://127.0.0.1:8000`. FastAPI source: `backend/api.py`.

The public v4.2 implementation has **four API endpoints**, plus the HTML page and explicit static mounts. **There is no public AMD/AI endpoint** and no operational rover simulation route.

## `GET /api/health`

Returns a basic service status, for example:

```json
{"service":"terrarover-terrain-science","status":"ok"}
```

This confirms the Python service responds, **not** that every DEM is valid or a third-party AI service is reachable.

## `POST /api/analyze`

Request (`Content-Type: application/json`):

```json
{"a":"La_Joya_NASADEM","b":"Mare_Tranquillitatis_SLDEM"}
```

The two values are **catalog region IDs**, not server paths. They must be distinct, syntactically safe and refer to entries with actual numeric DEM files in `data/regions/<id>/DEM.tif`.

The result includes keys such as:

```json
{
  "regions": {"a": "...", "b": "...", "bodies": {"a": "Tierra", "b": "Luna"}, "a_id": "...", "b_id": "..."},
  "metrics_a": {},
  "metrics_b": {},
  "feature_comparison": [],
  "legacy_cosine": null,
  "normalized_elevation_wasserstein": 0,
  "normalized_elevation_KS_statistic": 0,
  "pixelwise_difference": null,
  "fine_scale_comparison_permitted": false,
  "warnings": []
}
```

**This object is a field illustration, not measured results.** Actual values depend on the chosen raster pair. Other fields include coverage, native resolution, findings and interpretive notes.

Validation errors: invalid ID/identical pair (400), unknown region (404), unavailable source files/status (409), invalid numeric/scientific input (422), unavailable catalog (503).

Example PowerShell:

```powershell
$body = @{ a = "La_Joya_NASADEM"; b = "Mare_Tranquillitatis_SLDEM" } | ConvertTo-Json
Invoke-RestMethod -Uri "http://127.0.0.1:8000/api/analyze" -Method Post -Body $body -ContentType "application/json"
```

## `GET /api/chart?a=<ID>&b=<ID>`

Creates a PNG comparison figure from **numeric** source DEMs and the same analytic report. The return type is `image/png`, with `Cache-Control: no-store`. The endpoint may be expensive for very large rasters; do not expose it without deployment resource limits.

## `POST /api/community-upload`

A multipart form with:

| Parameter | Type | Meaning |
|---|---|---|
| `file` | GeoTIFF upload | One numeric raster band, max 16 MB |
| `title` | Form field | Public title, 3–80 characters |
| `body` | Form field | One of `Tierra`, `Marte`, `Luna` |
| `public_consent` | Form field | Must explicitly indicate consent to public publication (`true`, `on` or `yes`) |

Success status: **201**, with a new random `Community_...` ID and a **published / unverified** notice. This upload creates `DEM.tif`, `Mapa_2D.png` and `metadatos.json`—**not** the six-file canonical team bundle. See [Community submissions](COMMUNITY_SUBMISSIONS.md).

Potential errors: 403 (uploads disabled), 400 (consent), 415 (unsupported extension), 413 (too large), 422 (invalid content/geometry), 429 (basic per-hour cap) and 507 (community capacity).

## Static routes and browser navigation

- `/` and `/index.html` serve the web shell.
- `/src/*` serves frontend JS/CSS.
- `/assets/*` serves visual assets.
- `/data/*` serves published `catalog.json`, `chemistry.json`, regional DEMs and other allowed public files.
- Browser navigation uses hash routes such as `/#/inicio`, `/#/catalogo`, `/#/explorador`, `/#/comparador`, `/#/descubrir` and `/#/simulacion`, plus `/#/region/<ID>`.

Do not assume `/docs` or `/openapi.json` will be available: FastAPI's autogenerated documentation and OpenAPI URLs are deliberately disabled in the inspected source.

## Security expectations

- API consumer-supplied pair IDs are matched against the catalog; arbitrary filesystem paths are not accepted.
- Public uploads and scientific plots must still be protected by authentication, durable quotas, resource limits and operational monitoring before unrestricted deployment.
- Do not embed secrets in frontend JavaScript or publish `.env`.
